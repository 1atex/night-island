# Security Policy / Политика безопасности

## English

Please do not report vulnerabilities in public issues.

Use the private report form: the **Security** tab of this repository, then **Report a vulnerability**. Include the affected version, steps to reproduce and the impact. You will get an answer as soon as possible, and a fix is published before details are disclosed.

Only the latest release is supported.

## Русский

Пожалуйста, не сообщайте об уязвимостях в публичных issues.

Используйте приватную форму: вкладка **Security** этого репозитория, затем **Report a vulnerability**. Укажите версию, шаги воспроизведения и последствия. Ответ придёт как можно скорее, исправление выходит до публикации подробностей.

Поддерживается только последний релиз.
