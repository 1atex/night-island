# Night Browser downloads

Preview для совместной работы с Night Browser 0.9.2. Закрой предыдущую копию Island и запусти `night-island.exe`. Настройки существующего профиля сохраняются. Номер повторного скачивания в имени, например `night-island (1).exe`, поддерживается Browser 0.9.2.

Основа этой версии — указанный коммит [`7d9bc80`](https://github.com/1atex/night-island/commit/7d9bc801af2e41627ad7d15a6d2400bbda150aca), включая стекло, док и новые настройки. Он объединён с интеграцией отдельным merge-коммитом; история исходной ветки сохранена.

1. В настройках Island включи **Night Browser downloads** в разделе интеграций.
2. В Night Browser открой **Настройки → Интеграции** и включи загрузки в Island.
3. Начни загрузку. Наведение или нажатие на её индикатор в островке открывает список загрузок. Прогресс появится на острове, а во вкладке **Загрузки** будут доступны действия для её текущего состояния: пауза, продолжение, отмена или показ готового файла в папке.

В браузере появился компактный индикатор: он показывает файл и прогресс, а нажатие раскрывает настоящую вкладку загрузок Island. Браузер может брать цвета фона, акцент и настройку анимации из Island; это отключается отдельно в настройках интеграции. Цвета передаются по событию изменения, без опроса. Старые браузеры продолжают получать загрузки без новых возможностей.

Интеграция по умолчанию выключена. Передаются имя файла, состояние и количество байтов. Island также отдаёт три компонента цвета фона и акцента и разрешение анимации. Приватные загрузки, адреса сайтов и полные пути не передаются. Список ограничен 32 загрузками текущего сеанса подключения; готовые файлы из старой истории браузера не импортируются. Одновременно подключается один процесс браузера, включая его окна. При закрытии одного приложения второе продолжает работать.

Соединение — Windows named pipe с ACL текущего пользователя, проверкой SID и имени EXE обеих сторон, ограничениями размера сообщений и очередей. Это не защита от программы, которая уже выполняется под тем же пользователем и может подменить приложение. Порт TCP и отдельный фоновый процесс не создаются. Поток соединения ждёт события ОС; обновления прогресса объединяются с интервалом 500 мс. Если Island закрыт, браузер увеличивает интервал повторного подключения до 30 секунд.

Во время выполнения команды кнопки этой загрузки недоступны; повторный клик не отправляет вторую команду. При разрыве связи ожидающие команды сбрасываются. Вкладку «Загрузки» можно добавить в настраиваемую верхнюю панель.

Изменения интерфейса используют существующие отрисовку, шрифты и анимации Island. Поддерживается горизонтальное и боковое расположение. Запуск исполняемого файла после загрузки не выполняется: действие «Показать в папке» открывает проводник.

Сборка: `cargo test --locked --features demo`, затем `cargo build --locked --release --bin night-island` на Windows. Выпускаемый EXE собран без `demo`. Этот preview не подписан; автоматическая доставка через механизм обновлений Island не настроена.
