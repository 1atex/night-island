# Night Browser downloads

Preview для совместной работы с Night Browser 0.9.0. Закрой предыдущую копию Island и запусти `night-island.exe`. Настройки существующего профиля сохраняются.

1. В настройках Island включи **Night Browser downloads** в разделе интеграций.
2. В Night Browser открой **Настройки → Интеграции** и включи загрузки в Island.
3. Начни загрузку. Прогресс появится на острове, а во вкладке **Загрузки** будут доступны действия для её текущего состояния: пауза, продолжение, отмена или показ готового файла в папке.

Интеграция по умолчанию выключена. Передаются только имя файла, состояние и количество байтов. Приватные загрузки, адреса сайтов и полные пути не передаются. Список ограничен 32 загрузками текущего сеанса подключения; готовые файлы из старой истории браузера не импортируются. Одновременно подключается один процесс браузера, включая его окна. При закрытии одного приложения второе продолжает работать.

Соединение — Windows named pipe с ACL текущего пользователя, проверкой SID и имени EXE обеих сторон, ограничениями размера сообщений и очередей. Это не защита от программы, которая уже выполняется под тем же пользователем и может подменить приложение. Порт TCP и отдельный фоновый процесс не создаются. Поток соединения ждёт события ОС; обновления прогресса объединяются с интервалом 500 мс. Если Island закрыт, браузер увеличивает интервал повторного подключения до 30 секунд.

Изменения интерфейса используют существующие отрисовку, шрифты и анимации Island. Поддерживается горизонтальное и боковое расположение. Запуск исполняемого файла после загрузки не выполняется: действие «Показать в папке» открывает проводник.

Сборка: `cargo test --locked --features demo`, затем `cargo build --locked --release --bin night-island` на Windows. Выпускаемый EXE собран без `demo`. Этот preview не подписан; автоматическая доставка через механизм обновлений Island не настроена.
